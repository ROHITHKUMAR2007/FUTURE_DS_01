simulating real-world data analyst work for a retail business.

---

## 🎯 Objective

Analyze 5,000 sales transactions (2022–2024) to answer:
- Which products generate the most revenue?
- How do sales change over time?
- Which categories or regions are most profitable?
- Where should the business focus to grow faster?

---

## 🛠️ Tools Used

- Python 3.x — pandas, matplotlib, openpyxl
- Microsoft Excel — Dashboard formatting & visualization
- Git & GitHub — Version control and submission

---

## 📊 Dataset

- **Type:** Simulated retail sales data (self-generated)
- **Size:** 5,000 transactions
- **Period:** January 2022 – December 2024
- **Fields:** Order ID, Date, Region, Category, Product, Quantity,
              Unit Price, Discount, Sales, Profit

---

## 🔍 Analysis Performed

- Data cleaning & validation (nulls, negatives, date parsing)
- Revenue and profit trend analysis (monthly, quarterly, yearly)
- Category-wise performance (sales, margin, order volume)
- Regional breakdown (5 regions across India)
- Top 10 product ranking
- Customer segment comparison (Consumer, Corporate, Home Office)
- Year-over-year growth tracking
